# Data

Nothing in this directory that derives from the source images is redistributable.
What is here are factual split definitions and a hash pinning the manifest.

## What is committed

| path | what | why it is safe |
| --- | --- | --- |
| `splits/amdsd_splits.csv` | scan -> eye, patient, split, fold | assignment lists, no image content and no annotation-derived values |
| `splits/amdsd_patients.csv` | patient -> split, fold, counts | as above |
| `splits/manifest.sha256` | hash of the manifest used for every reported number | a checksum |

The splits carry no labels and no lesion areas — those derive from the annotation masks
and are regenerated by `scripts/prep/prep_amdsd.py`.

## Obtaining AMD-SD

3,049 B-scans, 156 eyes, 138 patients, all wet AMD, with pixel-level masks.

- Figshare release: search "AMD-SD OCT segmentation dataset"
- Take the **Figshare** copy, not the Kaggle mirror — the mirror drops
  `demographics.xlsx`, without which patient-level splitting is impossible and
  fellow eyes leak across folds
- Expected layout: `images/`, `masks/`, `demographics.xlsx`

Then rebuild the manifest and confirm it matches:

```bash
python scripts/prep/prep_amdsd.py --root <AMD-SD> --out data/amdsd_splits \
    --demographics <AMD-SD>/demographics.xlsx
shasum -a 256 data/amdsd_splits/manifest.csv    # compare with splits/manifest.sha256
```

The split is regenerated deterministically from `--seed 42`, so it will match
`splits/amdsd_splits.csv`.

## Obtaining AROI

1,136 annotated B-scans, 24 patients, used for external evaluation only — never trained on.

- Available from the University of Zagreb on request
- **The licence prohibits redistribution.** No AROI image, mask, crop, or cached
  embedding appears in this repository, and `.gitignore` blocks them
- Expected layout: `24 patient/patientN/{raw/ALL,mask/number,mask/colour}`

Class indices are undocumented in the release. `scripts/explore/inspect_aroi.py`
recovers and verifies them; the confirmed map is in DECISIONS.md.

## Not committed

- Raw B-scans and masks from either dataset
- Any AROI-derived measurement, including `results/aroi_*.csv` — the lesion areas in
  those files come from the restricted masks
- Cached encoder features (`amdsd_features/`, ~48 MB) and per-token features (~1.2 GB)
- Model predictions (`amdsd_preds/`) and checkpoints (`*.pth`, ~1.2 GB per fold)

Predictions and features were committed earlier in this repository's history and were
removed for licence reasons; the history was rewritten, so they are not recoverable from
old commits.
